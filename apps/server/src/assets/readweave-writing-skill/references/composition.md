# 先组织内容，再由程序排版

这是按需使用的排版工具，不是普通写作的前置步骤；仅在已有结构化素材或复杂混合文档确实需要程序排版时使用，不要求用户填写表单，不替代两份写作规则，也不增加外部助手

## 提交内容

把内容保存成一个对象，只有可选的 `title` 和必填的非空 `blocks` 数组

每个内容块用 `type` 选择下面一种结构，未列出的字段不要提交

| 类型 | 字段 | 用途 |
|---|---|---|
| `section` | `heading`、`blocks` | 按实际主题嵌套分区，程序计算标题层级 |
| `paragraph` | `text` | 一个意思或一条连续因果解释，不放多个可独立核对或操作的项目 |
| `list` | `items`、可选 `ordered` | 独立项目逐项提交，步骤用 `ordered: true` |
| `term` | `zh`、`en`、可选 `abbr`、`definition` | 首次专业术语，定义为三至五句的字符串数组，连续覆盖五段逻辑 |
| `source` | `id`、可选 `presentation`、可选 `language` | 引用单独保存的原始对象，不让模型重写原字符 |
| `code` | `language`、`text` | 新生成或带合法注释的解释副本，代码语句不执行 |
| `image` | `alt`、`url`、可选 `caption` | 实际图片与题注进入同一个居中容器，不生成或访问图片 |
| `table` | `text`、可选 `caption` | 新生成或重新排版的 Markdown 表格进入居中容器，列对齐标记设为居中，宽表只在内部容器横向滚动 |
| `formula` | `text` | 公式表达式，不含外层双美元定界符，程序加入独立公式块 |

`list.items` 中每项是含 `text` 的对象，子项放入 `children` 数组，子项继续使用同一结构；子步骤需要编号时设置该父项的 `children_ordered: true`

普通层级由程序增加四个空格，编号变长时按父项实际内容起点增加必要缩进，避免子项被错误提升为同级；这遵循 [CommonMark 列表项目规则](https://spec.commonmark.org/0.31.2/#list-items)，不是增加新的写作文风限制

独立事实、比较维度、操作和问题直接放进不同项目；不能因为发生在同一流程，就合进 `paragraph` 或一个 `text`；程序只保证已经分开的项目会分行，不会猜出你藏在句子里的多个事项

普通文本字段不手写标题、列表标记或换行，程序处理这些外层格式；行内代码、链接和公式可以保留，不能用它们给普通英文名称取得豁免

术语定义数组不是五个对外子列表，程序把它连成一个完整定义项；语句内部的其他术语仍须配齐中英文，不能借结构省略原文、适用条件或区别说明

## 原始对象

需要逐字保留的原始代码、日志、表格、引用和已有公式，先直接从材料提取到单独的来源对象文件

该文件是对象标识到原始字符串的映射，所有已提供对象都必须有对应 `source` 内容块；这只证明原字符被保留，不证明长文事实已经全部解释

- `presentation: "raw"` 原样插入已成型的表格、图片或公式等对象；图片增加 `layout: "centered_image"`，表格增加 `layout: "centered_table"` 时只在原对象外增加居中容器，表格容器同时限制内部横向滚动
- `presentation: "quote"` 只增加逐字引用的外层标记
- `presentation: "code"` 只增加代码或日志围栏，可用 `language` 指定真实语言

居中原始图片或表格可以增加可选 `caption`，程序会把题注放在同一个外层容器中；原始对象的字符保持不变，多图原表的单元格未预先设置居中且又不能改写原表语法时，需要在正文自然说明这个限制

长文待改写的普通正文不放进逐字对象映射来冒充已解释；仍从原材料逐段核对改写中的落点

## 执行与修复

以当前技能实际路径替换下面的 `COMPOSE`，输入和输出均放在本次任务的临时目录

```text
python -X utf8 COMPOSE --document content.json --sources originals.json --output draft.md
```

没有逐字对象时省略 `--sources`；宿主明确要求子列表前空行时，增加 `--nested-list-spacing host-required`

程序只创建尚不存在的初稿文件，拒绝覆盖已有正文；初稿生成后使用 [现有检查与精确补丁](local-review.md)，不能修改整份结构文件后重新渲染来掩盖局部错误

生成文本字段只统一边缘空白并去掉行末中文句号和分号，其他字符及原始对象不做语义替换；句中标点、独立性、术语身份、事实与解释完整性仍由助手逐块复核

结构输入有错误时，只修正报错字段，不重新组织已经正确的全文；接口纠错与后续局部修复共用最多两次纠正机会；仍无法运行时保留已有内容并按规则交付，不伪造程序生成或检查成功

没有本地工具时按同样的内容结构直接写作并自查，不要求用户安装运行环境
